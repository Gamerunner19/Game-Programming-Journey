# Gamerunner's Tic-Tac-Toe
A simple Multiplayer Tic-Tac-Toe made in Python using Turtle graphics

## Features
- Two player co-op
- Loops the game after tie/win
- Turn-switching system
- Responsive gameplay

## What I Learned
- Tkinter mouse click handling
- Controlling drawing X/O depend on whose turn it is
- Storing/reading game stats
- Resetting a game while keeping an active loop
- Working with a tkinter canvas
