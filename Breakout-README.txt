# Gamerunner's Breakout
A simple Breakout-style game made in Python using Turtle graphics.

## Features
- Paddle movement
- Ball, Brick, and Paddle collisions
- Brick destruction
- Score tracking
- Ever increasing ball speed
- A pause menu

## What I Learned
- Collision detection
- Bounce physics
- Debugging gameplay systems
- Calculating and manipulating velocity and angles
- Framerate handling
